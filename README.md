# CRM-bot — заявки из 1С CRM в Telegram

Робот раз в несколько минут читает список заявок в веб-клиенте 1С CRM (браузер Chromium без окна)
и присылает исполнителям в Telegram новые заявки, изменения и передачи, утром — открытые заявки,
вечером — итог дня. В 1С робот ничего не меняет: только читает.

## Требования

| | |
| --- | --- |
| Система | Debian 13 без графики |
| Процессор / память / диск | 2 ядра / 2 ГБ (минимум 1,5 ГБ) / 10 ГБ |
| Время | часовой пояс Казахстана (`timedatectl set-timezone Asia/Almaty`) и точное время (NTP) — по нему считается рабочее время |
| Выход в интернет | `api.telegram.org:443`, `crm.asia-servis.kz:4682`; для установки и обновлений — `deb.debian.org`, `pypi.org`, `files.pythonhosted.org`, `api.github.com`, `github.com`, `objects.githubusercontent.com` |
| 1С | отдельный пользователь для робота (достаточно права читать заявки) |
| Telegram | бот, созданный у @BotFather, — его токен |

## Установка

Все команды — от root (или через `sudo`), по одной.

1. Часовой пояс (по нему робот считает рабочее время):
   ```
   timedatectl set-timezone Asia/Almaty
   ```
2. Скачать и распаковать последнюю версию (первая команда убирает остатки прошлой распаковки):
   ```
   cd /root && rm -rf crm-bot crm-bot-linux.tar.gz
   ```
   ```
   curl -LO https://github.com/asia-servis-crm/crm-bot/releases/latest/download/crm-bot-linux.tar.gz
   ```
   ```
   tar xzf crm-bot-linux.tar.gz
   ```
   Запустить установку (ставит `chromium`, `python3-venv`, создаёт пользователя `crm-bot`,
   службу `crm-bot` и команду `crm-bot`; 2–5 минут). При повторной установке данные сохраняются:
   ```
   cd /root/crm-bot && ./install.sh
   ```
   Если `curl` нет: `apt update && apt install -y curl`.
3. Настройки — каждая команда сама спросит значение. Логин виден при вводе; пароль и токен
   вводятся скрыто (на экране ничего не появляется — это нормально) и не остаются в истории команд:
   ```
   crm-bot login
   ```
   ```
   crm-bot password
   ```
   ```
   crm-bot token
   ```
   Если в 1С входят без пароля — в `crm-bot password` просто нажать Enter и ответить «да».
4. Проверка: вход в 1С и чтение списка (около минуты):
   ```
   crm-bot test
   ```
5. Запуск:
   ```
   crm-bot start
   ```
6. Первый админ: человек пишет боту в Telegram (любое сообщение), затем на сервере:
   ```
   crm-bot users
   ```
   ```
   crm-bot admin add ID
   ```
   Админ, добавленный командой, — **защищённый**: из Telegram его не снять и не заблокировать.
   Дальше людьми управляют админы в Telegram: новые люди пишут боту, админы назначают им исполнителя
   из 1С (кнопка «👥 Пользователи») или делают админами.

## Каждый день

| Что | Команда |
| --- | --- |
| Работает ли, когда была последняя проверка, проблемы | `crm-bot status` |
| Журнал | `crm-bot log` (или `crm-bot log 200`) |
| Перезапуск / остановка / запуск | `crm-bot restart` / `crm-bot stop` / `crm-bot start` |
| Настройки (пароль и токен скрыты) | `crm-bot show` |
| Кто писал боту, админы | `crm-bot users`, `crm-bot admin add ID`, `crm-bot admin remove ID` |
| Справка | `crm-bot help` |

Команды `login`, `password`, `token`, `url`, `admin` сами останавливают робота на время изменения
и запускают снова.

## Настройки в Telegram

У всех админов: «ℹ️ Статус» → «⚙️ Настройки» (или `/settings`): адрес, логин и пароль 1С, токен бота,
рабочее время, интервал проверок (1–60 мин, по умолчанию 1), тревога (через сколько минут без удачной
проверки писать всем «робот не работает», по умолчанию 15). Сообщения с паролем и токеном бот сразу удаляет.

Смена токена проверяется (Telegram должен принять токен). Если это другой бот — всем пользователям и
админам придёт просьба открыть новый бот и нажать «Старт»; кто ещё не нажал — видно в настройках.
Если с новым токеном бот не заработает, в течение часа он сам вернёт прежний.

## Сообщения о проблемах

- **Неверный логин или пароль 1С** — админам сразу; робот пробует войти раз в 15 минут, пока данные не исправят.
- **Робот не работает** (CRM не читается дольше заданного времени) — всем, с причиной (1С не отвечает,
  неверный логин и т. п.); после — «снова работает, перерыв с … до …».
- **Робот не работал** (сервер или служба перезапускались) — админам; пользователям — если перерыв задел
  рабочее время.
- **Не работает сам токен бота** — в Telegram сообщить невозможно: видно в `crm-bot status`
  («ПРОБЛЕМА С TELEGRAM») и в журнале. Исправить: `crm-bot token`.

## Обновление

«ℹ️ Статус» → «🔎 Проверить обновления» (у любого админа): бот показывает, что нового в новой версии,
и спрашивает; после «⬆️ Обновить» ставит её и перезапускается (около минуты).

Если после обновления робот не работает:
```
crm-bot rollback
```
Изменения в службе или в команде `crm-bot` (бывает редко) кнопкой не ставятся: робот работает не от
root и не может менять системные файлы. Бот предупредит об этом заметно — до обновления, после него
и в «ℹ️ Статус» (и `crm-bot status`); тогда нужна переустановка — шаг 2 из «Установки» (данные сохраняются).

## Где что лежит

| Путь | Что |
| --- | --- |
| `/opt/crm-bot/app` | программа (`app.old` — предыдущая версия) |
| `/opt/crm-bot/venv` | Python и Playwright |
| `/var/lib/crm-bot` | данные: `settings.json` (настройки, права 600), `users.json` (люди), `state.json` (служебное), `alive.txt`, `last_error.png` (снимок 1С при последней ошибке) |
| `/etc/systemd/system/crm-bot.service` | служба |
| `/usr/local/bin/crm-bot` | команда |

Удалить полностью: `systemctl disable --now crm-bot`, удалить перечисленное выше и пользователя `crm-bot`.
